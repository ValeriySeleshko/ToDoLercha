# Сбор базы продуктов питания Украины (Zakaz.ua)

Инструмент для выгрузки продуктов питания со штрихкодами (EAN-13) и КБЖУ (калории, белки, жиры, углеводы) с платформы **Zakaz.ua** по крупнейшим супермаркетам Украины:
* **NOVUS**
* **METRO Cash & Carry**
* **Auchan**
* **MEGAMARKET**
* **EkoMarket**
* **Tavria V**
* **Ultramarket**
* **Torba** (Чернівці / Рівне)
* **Chudo Market** (Харків)

---

## 🚀 Как пользоваться

### 1. Запуск сбора базы
Просто дважды кликните по:
```text
Запустить_Скачивание.bat
```
Скрипт начнет аккуратный обход всех продуктовых отделов.

### 2. Пауза и продолжение в любой момент
- Вы можете в любой момент нажать **`Ctrl + C`** в окне консоли или просто закрыть его.
- Прогресс автоматически сохраняется в `progress.json`.
- При повторном клике по `Запустить_Скачивание.bat` скрипт **продолжит с того же магазина, отдела и страницы**, где остановился!

### 3. Экспорт готовой базы
Когда сбор завершен (или набрано достаточное количество товаров), запустите:
```text
Экспорт_В_Приложение.bat
```
Скрипт создаст:
1. `ua_food_database.json` — ультракомпактный JSON.
2. `ua_food_database.js` — готовый скрипт для подключения прямо в приложение.
3. `ua_food_database.csv` — файл таблицы для заливки в облачную базу (Supabase / PostgreSQL).
4. Автоматически скопирует файлы в `assets/` вашего проекта Plan4U для сборки в APK.

## 🥑 Интеграция с Listex.info (Визуальный скрипт)

Вы можете пополнять базу продуктами прямо с платформы **Listex.info**:

### 1. Интерактивный Визуальный Дашборд (Веб-GUI)
Дважды кликните по:
```text
Запустить_Listex_Визуальный.bat
```
В браузере откроется панель (`http://localhost:3737`):
- **Быстрый поиск и добавление:** введите штрихкод (например `4820077822765`) или ссылку на товар Listex, просмотрите фото, проверенные данные КБЖУ и сохраните в Plan4U в один клик.
- **Пакетный импорт:** вставьте список штрихкодов для автоматического опроса и сохранения.
- **Инспектор базы:** мгновенный поиск среди 76 000+ товаров в вашей базе для проверки штрихкода.

### 2. Сборщик каталога Listex
Дважды кликните по:
```text
Скачать_Листекс_Каталог.bat
```
Скрипт автоматически обойдет продуктовые категории (хлеб, бакалея, молочка, сыры и т.д.) с красивым ANSI-дашбордом и сохранением прогресса в `listex_progress.json`.

## 🛡️ Безопасность и настройки

- **Скорость:** По умолчанию скрипт запрашивает 50 товаров раз в 2 секунды (~25 товаров/сек). Это совершенно незаметно для серверов Zakaz.ua и Cloudflare.
- **Фильтрация:** Автоматически пропускаются непродовольственные категории (химия, табак, зоотовары, одежда, канцелярия).
- **Дедупликация:** Если один и тот же товар продается в разных источниках, скрипт объединяет их по штрихкоду и оставляет максимально полную пищевую ценность.
