# 🎨 Руководство по добавлению стикеров в Plan4U

Полная инструкция и готовый шаблон промта для быстрого добавления новых наборов стикеров в приложение.

---

## ⚡ 1. Готовый шаблон промта для AI

> **Как использовать:** Скопируйте текст ниже, вставьте имя пака и прикрепите изображение листа со стикерами.

```text
Добавь новую вкладку со стикерами в блокнот:
- Название вкладки: "<ИМЯ_ВКЛАДКИ>" (например: "Совы", "Драконы", "Сладости")
- Иконка/эмодзи вкладки: <ЭМОДЗИ> (например: 🦉, 🐉, 🍰)
- Файл листа со стикерами: <ИМЯ_ФАЙЛА.jpg/png>

Требования к интеграции:
1. Нарежь стикеры в прозрачные PNG (assets/stickers/<pack_name>/<prefix>_XX.png) с автообрезкой полей и удалением белого фона листа.
2. Добавь вкладку в `#stickersCategoriesBar` в `index.html`.
3. Добавь массив в `STICKERS_CATALOG` и поддержку префикса в `findStickerDef` в `app.js`.
4. Карточки в шторке должны быть квадратными 1:1 без текстовых подписей.
5. Прозрачность стикеров на листе должна быть 50% (opacity: 0.50).
6. Синхронизируй файлы в папку `www/` и обнови версию кэша Service Worker.
```

## 📐 2. Стандарты и правила стикеров в проекте

| Параметр | Значение / Правило |
| :--- | :--- |
| **Формат спрайтов** | `.png` с прозрачным альфа-каналом (фон листа удален, белый контур стикера сохранен). |
| **Папка в проекте** | `assets/stickers/<имя_пака>/` (например, `assets/stickers/fauna/`). |
| **Именование файлов** | `<prefix>_01.png`, `<prefix>_02.png`, ... с двузначными номерами. |
| **Сетка в шторке** | Квадратные ячейки `1:1`, **без текстовых подписей**. |
| **Отображение на листе** | Полупрозрачность **50%** (`opacity: 0.50`), режим наложения `mix-blend-mode: multiply` (в темной теме `normal`). |
| **Главная кнопка вызова** | Круглая `56×56px` с иконкой `✨`, центрирована внизу экрана на одной линии с кнопкой `+` и Питомцем. |
| **Поведение при перетягивании** | Шторка стикеров мгновенно скрывается при захвате стикера, чтобы весь лист был виден. |
| **Контекстное меню** | Долгое нажатие или клик по стикеру открывает меню (Переместить, Повернуть, Масштаб, Удалить) с защитой от вылета за края экрана. |

## 🛠️ 3. Пошаговый алгоритм добавления нового пака (под капотом)

### Шаг 1. Нарезка спрайтов
Используется скрипт PowerShell с C# для идеального определения границ, заливки прозрачности и центрирования каждого стикера:

```powershell
# Шаблон вызова экстрактора:
# [StickerExtractor]::Extract("Sticker_Sheet.jpg", "assets\stickers\<pack>", "<prefix>", <rows>, <cols>, <minX>, <maxX>, <minY>, <maxY>)
```

### Шаг 2. Добавление вкладки в `index.html`
В контейнере `#stickersCategoriesBar` добавляется кнопка:
```html
<button type="button" class="sticker-cat-btn" data-category="pack_name">✨ Название</button>
```

### Шаг 3. Регистрация в `app.js`
1. В объекте `STICKERS_CATALOG`:
```javascript
const STICKERS_CATALOG = {
  // ... другие паки ...
  pack_name: Array.from({ length: TOTAL_COUNT }, (_, i) => {
    const num = String(i + 1).padStart(2, '0');
    return {
      id: `prefix_${num}`,
      img: `assets/stickers/pack_name/prefix_${num}.png`
    };
  })
};
```

2. В методе `findStickerDef(typeId)`:
```javascript
if (typeId?.startsWith('prefix_')) return { id: typeId, img: `assets/stickers/pack_name/${typeId}.png` };
```

### Шаг 4. Синхронизация файлов в `www/`
```powershell
Copy-Item -Path "assets\stickers\*" -Destination "www\assets\stickers\" -Recurse -Force
Copy-Item -Path "index.html", "style.css", "app.js", "sw.js" -Destination "www\" -Force
```
